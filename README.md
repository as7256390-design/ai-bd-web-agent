# AI Web Agent for Lead Qualification

This project demonstrates a working AI-driven web agent that identifies,
enriches, and prioritizes high-probability business development leads for
3D in-vitro model platforms.

## Key Capabilities
- Identification from scientific publications and conference-style data
- Profile enrichment including role, location, company HQ, and contact inference
- Weighted "Propensity to Buy" scoring engine (0–100)
- Searchable dashboard with CSV export

## Architecture
- Streamlit frontend
- Modular Python backend
- Scoring logic aligned with BD decision-making workflows

## Scalability
The system is designed to integrate with LinkedIn, Sales Navigator,
Crunchbase, Proxycurl, and CRM systems when API credentials are available.
